# Hospital Website

A simple hospital landing page built with plain HTML and CSS.

I made it as a training project to practice page layout and styling.

## What I practiced

- Page structure with HTML
- Styling and layout with CSS
- Building a multi-section website from scratch

## How to run

No install needed. Download the project and open the main HTML file in any web browser.
